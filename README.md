# CivicLens - Smart Civic Issue Reporting System

## 📌 Project Description.      

CivicLens is a smart civic issue reporting system developed to help citizens report public issues easily and efficiently.  
The platform allows users to submit complaints related to roads, garbage, water leakage, street lights, and other civic problems.

The system helps authorities track issues, manage reports, and improve communication between citizens and administration.

This project is built using Django and provides a clean and user-friendly interface for issue management.

# ✨ Features

- 📝 User Registration and Login
- 📍 Report Civic Issues
- 📷 Upload Issue Images
- 📊 Admin Dashboard
- 🔍 Track Complaint Status
- 📂 Issue Management System
- 📄 PDF Report Generation
- 🏆 Certificate Generation
- 🎨 Responsive User Interface
- 🔐 Secure Authentication System

# ⚙️ Installation Steps

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/vinodmangate26/CivicLens-Smart-Civic-Issue-Reporting-System.git
```

---

## 2️⃣ Open Project Folder

```bash
cd CivicLens-Smart-Civic-Issue-Reporting-System
```

---

## 3️⃣ Create Virtual Environment

```bash
python -m venv venv
```

---

## 4️⃣ Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

---

## 5️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

---

## 6️⃣ Run Migrations

```bash
python manage.py migrate
```


## 7️⃣ Start Server

```bash
python manage.py runserver
```
